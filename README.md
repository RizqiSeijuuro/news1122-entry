A pure Python 3.13, standard-library-only program that renders a 1024x1024 PNG briefing of 22 November 2026 world news straight from pixels: a hand-rolled PNG encoder (zlib + struct) and an embedded 5x7 bitmap font draw a dark navy "WORLD NEWS" title bar above a 2x3 grid of colour-coded story cards covering the Sparta II drone strike and Finland's war-spillover warning in the Baltic, the deadly missile and rocket attack on Kryvyi Rih, Saudi/Bahraini interceptions of Houthi and Iranian missiles over the Gulf, Iran's "act of war" response to the US economic blockade, and Trump's call for any future Iran nuclear deal to be permanent.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
